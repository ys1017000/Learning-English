英語学習サイト：タップ操作の共通修正版

対象：index.html / quiz.html / writing.html / speaking.html / phrases.html / review.html / conversation.html / guide.html

今回の変更
- タッチ操作で既存の click ハンドラーが動かない場合に備え、touch/pen の pointerup から既存の click 処理を呼ぶ共通フォールバックを追加。
- 同じタップで二重実行されないよう、直後のブラウザー生成 click を抑制。
- 通常クイズの回答選択肢について、回答後に disabled の既定半透明表示にならないよう修正。
- 正解選択肢を緑系、選んだ不正解を赤系で塗り分け。
- 形容詞・副詞などの選択式ミニクイズでも、回答後に選択肢をロックして正解／選んだ不正解を色で表示。
- 既存の問題データ、出題順の仕組み、採点、解説、学習記録の処理は維持。

適用方法
1. ZIP内の8つのHTMLファイルをGitHubリポジトリ内の同名ファイルに置き換えてください。
2. README-JP.txt は説明用なので、サイトの公開ディレクトリに置かなくても構いません。
3. GitHubへコミット後、公開サイトを再読み込みして確認してください。スマホではキャッシュを避けるため、ページを再読み込みしてからテストしてください。

確認状況
- JavaScript構文チェック、ZIPの整合性チェックを実施。
- この実行環境ではブラウザー操作が管理者ポリシーでブロックされるため、実機ブラウザーでのタップ動作テストは未実施です。公開後の実機確認が必要です。
