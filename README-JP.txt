英語学習サイト：タップ操作修正版 v2

対象：index.html / quiz.html / writing.html / speaking.html / phrases.html / review.html / conversation.html / guide.html

今回の変更
- 前回の「pointerup で合成 click を発生させ、あとから本来の click を抑制する」方式を見直しました。
- タップ時、既存の onclick ハンドラーがあるボタンはその処理を直接呼び出します。画面を描き直す操作でも、合成 click と通常 click の競合を避ける狙いです。
- onclick ではなく addEventListener で登録されているボタンは click() にフォールバックします。
- 実リンク（a href）は通常のブラウザー動作を維持します。
- 既存の問題データ、出題順、採点、解説、学習記録の処理は意図的に変更していません。

適用方法
1. ZIP内の8つのHTMLファイルをGitHubリポジトリ内の同名ファイルに置き換えてください。
2. README-JP.txt は説明用なので、サイトの公開ディレクトリに置かなくても構いません。
3. GitHubへコミット後、公開サイトを再読み込みして確認してください。スマホではキャッシュを避けるため、ページを再読み込みしてからテストしてください。
